# MY CLOUD AI – Full Website Package

## Included
- `index.html` – main dashboard
- AI studio pages: Video, Image, Chat, Audio, Voice, Coding, Design, Productivity
- Cloud option pages: GPU, Storage, Cloud Notebooks
- Utility pages: My Files, Downloads, Login, Signup, Profile, Settings, Help, About, Privacy, Terms

## Install on GitHub Pages (Android)
1. Extract this ZIP on your phone.
2. Open your GitHub repository `bksahare70/my-cloud-ai`.
3. Use **Add file → Upload files**.
4. Select all extracted `.html` files together and upload them to the repository root.
5. Commit changes.
6. Open `https://bksahare70.github.io/my-cloud-ai/` and test each page.

Do not upload the ZIP itself expecting GitHub Pages to unpack it. Upload the extracted HTML files.
Keep your existing `index-backup-2026.html` backup.

## Important limitations
This is a static website directory. It does not create a real GPU server, private cloud drive, authentication backend, file uploader, or hosted AI models. The cloud pages link to third-party services. Free tiers and URLs may change.

## Quality checks
All HTML files were checked for basic HTML structure, local navigation targets and JavaScript syntax. This cannot guarantee that third-party websites remain online or that every external provider works in every country/device.
