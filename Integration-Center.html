Security rules
  • Never paste a Supabase service_role key or private AI API key into GitHub HTML or JavaScript.
  • Only the Supabase publishable/anon key belongs in the browser, protected by correct Row Level Security policies.
  • Private AI provider keys must be stored as server-side secrets in a backend function or worker.
  • Free provider tiers have usage limits and can change; no unlimited GPU or AI API is promised.
