MY CLOUD AI — COMPLETE UPGRADE PACKAGE

This package preserves the supplied project files and adds an Automation Hub workflow checklist plus a Dashboard entry.

INSTALL
1. Keep a backup of your current GitHub repository.
2. Extract this ZIP on your phone.
3. Upload the CONTENTS of the my-cloud-ai-main folder to the ROOT of your existing GitHub repository.
4. Allow GitHub to replace same-named files when prompted, and add the new Automation-Hub.html and UPGRADE-README.txt.
5. Commit changes, then open your GitHub Pages website and test it.

IMPORTANT LIMITS
- This is a static GitHub Pages website. It does not provide its own GPU, host AI models, or run background automation.
- Existing AI Studio links open third-party services. Actual AI generation requires each provider's API and, for secret keys, a secure backend.
- Automation Hub currently stores a local checklist in the current browser only; it is not a scheduler or cloud automation engine.
- Keep Supabase publishable key only in the public config; NEVER add service_role, secret API keys, passwords, or tokens to frontend files.
- Verify Supabase Row Level Security and Storage policies before storing private files.
